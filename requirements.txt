# LEDControl — Python dependencies

# Derived from the actual imports across the codebase, pinned to the versions
# that were installed and working in the original venv (Python 3.14.4, macOS
# arm64, Homebrew). Not a pip freeze — that would have captured all 68 packages
# in the environment including transitive ones, which makes the real
# dependencies impossible to see.
#
#   python3 -m venv venv
#   source venv/bin/activate
#   pip install -r requirements.txt
#
# NOTE: opencv-contrib-python, not opencv-python. mediapipe depends on the
# contrib build, and installing both puts two copies of OpenCV (and of SDL2)
# in the venv, which prints a wall of "Class SDL... is implemented in both"
# warnings whenever an app starts. The contrib build includes everything
# opencv-python does (cv2.aruco, imshow), so one package is enough.
#
# NOTE: pygame-ce, not pygame. They install to the same `pygame` namespace but
# are different projects; installing vanilla pygame will mostly work and then
# differ somewhere subtle.
#
# PyAudio needs portaudio on the system first:  brew install portaudio
# openai-whisper pulls in torch (~2GB), which is why a fresh install is slow.
