# Documentation Rhythm

Not a calendar — a set of triggers. The brief already flags the trap: a weekly
cadence on the slowest platform (WordPress) turns into homework and produces thin
posts. So instead of "post X every Y days," each channel fires off a real event.
The only thing on an actual clock is a private review checkpoint, which decides
*whether* to act — it never forces output.

---

## The one habit everything else depends on

**End of every work session → "log this."**

Draft a `JOURNAL.md` entry from the git diff and the session's conversation. Two
minutes. This is the raw material every downstream post gets pulled from, so
nothing has to be reconstructed from memory weeks later. If this habit slips, the
rest of the rhythm starves.

---

## Channel triggers

| Channel | Trigger | Natural frequency | Effort |
|---|---|---|---|
| GitHub | Every session (commits) | Continuous | Low — already working |
| JOURNAL.md | Every session, on "log this" | Continuous | ~2 min |
| Instagram | A sketch produces a moment worth 15–45s, same day | Irregular, could be daily | Low — no editing |
| YouTube | A sketch/instrument milestone earns the wide, in-room shot | Roughly every few weeks | Medium — one real take |
| WordPress | JOURNAL.md has enough for the Hoff template (hook, rules, a genuine surprise) | Every 2–8 weeks | High — the only planned writing |
| README.md hub | A new YouTube video goes up | Tied to YouTube | Low — one link added |

Reading down that table: Instagram runs on the day something happens.
YouTube and WordPress run on accumulation — they wait for the JOURNAL to hand them
enough material, rather than being scheduled independently.

---

## The one clock: biweekly review

Every two weeks, a private checkpoint — not a publishing deadline:

1. Skim JOURNAL.md entries since the last checkpoint.
2. Ask: has anything resolved into an idea with a real hook, a rule set, and an
   honest surprise? If yes → draft a WordPress post from it.
3. Ask: has anything reached the point where the physical-panel shot is worth
   setting up? If yes → schedule the YouTube shoot.
4. If the answer to both is no, skip. Nothing is owed. The checkpoint's job is to
   notice accumulation, not to manufacture it.

This is the only recurring event worth automating — a nudge to open JOURNAL.md and
ask the two questions above, not a deadline to publish.

---

## Why this shape

- Instagram already self-regulates (frequency = however often sketches happen) —
  it doesn't need a trigger imposed on it beyond "same day."
- YouTube and WordPress are slow by design; forcing a cadence on them fights the
  brief's own stated failure mode.
- The only fragile point in the system is the JOURNAL habit — if that holds, both
  slow channels have something to draw from whenever the biweekly checkpoint asks.
