# Studies

**Output Layer 02.** A sketch that has met someone who isn't me, and survived it.

The Periphery Center's gate for this tier is "survived at least one Exchange."
POP doesn't run the Culture Cycle, so the equivalent here is the lightest real
public contact available: the piece went out — an Instagram clip, a YouTube
take, shown to someone in the room — it got a response, and I still believed in
it afterward. That last part matters. Posting something is not the gate;
posting it and still wanting it is.

What changes once a piece is here: it's iterating toward form rather than
exploring. Changes get more deliberate, the tuning constants stop moving every
session, and it's worth keeping notes on what the responses actually were.

Promote by `git mv`-ing the file up from `../sketches/` and adding a line to
`/CYCLE.md` at the repo root. Nothing in the file needs editing — the shared
canvas harness lives in `../_pixel_canvas.py` and is resolved relative to the
parent directory precisely so that moving between tiers never breaks anything.

Empty for now. Everything so far is still a sketch.
